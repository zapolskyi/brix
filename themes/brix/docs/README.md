## Макети

Вихідні артборди Claude Design лежать локально в `docs/design-source/`
і **навмисно не входять у репозиторій** — це робочі файли редактора,
а не частина теми.

```bash
# подивитись макети
open docs/design-source/preview/index.html

# перезібрати після правок (правити треба src/parts/*.mjs)
cd docs/design-source/src && node build.mjs && node export.mjs ../preview
```

## Як вести документацію

- **Закінчив сесію** — оновив `PROGRESS.md`: таблицю фаз, «Наступний крок», журнал.
- **Ухвалив нетривіальне рішення** — дописав запис у `DECISIONS.md`.
- **Змінився обсяг** — правиш `PHASES.md`, а не тримаєш зміну в голові.
