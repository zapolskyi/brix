21 артборд у `design-source/` (поза репозиторієм). Цей файл — карта того, що
в них є, щоб у розробці не відкривати щоразу полотно.

Переглянути: `open design-source/preview/index.html`
Перезібрати після правок: `cd design-source/src && node build.mjs && node export.mjs ../preview`
Правити треба `src/parts/*.mjs`, а не згенерований HTML — його перезапише.

## Дизайн-система

Уся в `design-source/src/parts/base.mjs`. При верстці переноситься в SCSS:
токени з `:root` → `assets/scss/abstracts/_tokens.scss`, класи компонентів →
`assets/scss/components/`.

--green  #A7B48C   --green-d  #5B6841

--mill   #F2F3EE   --paper #FBFBF8  --stone #E5E7DE
--line   #D4D6CB   --muted #6C6763

фони тегів обробки:
--nat #F3DFE2  --wsh #E7EBDD  --hny #F8EDD7  --lab #E3E2DD  --cor #EDEEE8

--ui Onest · --dp Unbounded · --mo IBM Plex Mono

Базовий кегль 17px/1.55. Заголовки: `.h1` 64 · `.h2` 44 · `.h3` 26 · `.h4` 19.

### Що врахувати при верстці

- **`.pack` — container queries** (`cqw`), не `vw`. Потрібен
  `container-type: inline-size` на батьку, інакше пачка розсиплеться.
- **Пачка — CSS, не зображення.** Колір береться з таксономії «Обробка»,
  тож вона рендериться з даних товару, а не завантажується.
- **Шрифти** в макетах підключені з Google Fonts. У темі — локальні `woff2`
  з підмножинами cyrillic/latin, як на TORQ, інакше LCP не витримає бюджет.
- **Плейсхолдери `.ph`** мають підпис — при заміні на реальні фото
  не забути `width`/`height`, інакше поїде CLS.
- **Макети статичні:** станів `:hover`, `:focus-visible`, помилок валідації
  й порожніх станів у них немає — це добудовується при верстці.
